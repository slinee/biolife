# BIOFORM

Pixel-based artificial life with seeded resource ecology, Conway rules, batch experiments, and CSV/JSON exports.

Requires Node.js 22+. No dependencies to install.

```sh
npm run dev
```

Open http://localhost:3003. Space pauses; Tools, Experiment, and Data contain the controls.

Tests: `npm test` · Static build: `npm run build`

An exploratory simulation, not a predictive biological model.
